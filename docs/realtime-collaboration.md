# 实时协作与分屏编辑

客户端 2.9.0、服务端 2.6.0 引入可选的原生实时协作。两端版本独立演进；普通团队 Git 协作仍可使用。

## 使用流程

1. 管理员在团队项目卡片选择「开启协作模式」。选定分支应没有冲突、未提交修改或未发布提交。先保存并发布个人修改。服务器还会检查成员工作树与正在使用的项目会话。
2. 打开项目时使用团队共享分支并选择本地文件夹。替换非空目录需要确认。客户端先准备完整快照，再替换本地文件。未发送的文本修改保留在本机恢复草稿。
3. 编辑区右上角的分屏按钮或 `Ctrl+\` 将当前视图复制到右侧。文本视图共享同一份内容，各自保留光标与滚动位置。Notebook、Agent 和插件详情的副本显示预览，点击后把原视图切到这一侧。可以在任意一侧选择其他标签，分别编辑不同文件。
4. 对方的微缩头像和姓名会跟随光标。文件树中的头像只在编辑成员变化时更新。撤销和重做只影响自己的操作。保存等待服务器持久化确认。重连补齐同一协作版本的编辑及文件新增、改名与删除，已初始化的窗口直接恢复。
5. 运行当前代码或项目任务时保持当前面板。团队下边栏可展开查看共享运行的状态、时间和输出，也可输入、停止、处理删除请求、创建版本和保存个人快照。运行者离开窗口后，共享运行可以继续。
6. 管理员选择「关闭协作模式」后，服务器先将最终权威内容提交并推送到团队 Git，再切换 epoch。导出失败会保留原模式。退出成功后清除实时正文、节点及共享运行记录。本地映射持久化实时 epoch，退出或离线重开时从最终 Git 分支刷新文件，再恢复普通同步。

## 编辑者与删除

文件持续显示在任一编辑区且编辑过，就保持该会话的编辑状态。切走后保留 10 秒，切回则取消释放。同一用户可在多个文件、窗口或设备上编辑。客户端每 15 秒发出心跳，服务器在 60 秒没有消息后释放会话。

删除请求以当前编辑者的用户 ID 去重，阻止后来者打开该文件。现有编辑者仍可继续修改，同意删除不会强制只读。所有被询问者同意，或其全部会话释放文件后，才完成删除。任一人拒绝、申请人撤销或经过 180 秒都会取消。文件夹请求覆盖其子项。

## 数据与运行边界

- 服务端项目下 `realtime.json` 保存权威文件树、CRDT 节点、tombstone、epoch 与最近的幂等回执；先持久化再确认。共享内容和成员本地/云端副本分离，前台文件按需拉取正文，新增、改名、删除及编辑者状态全域广播。
- 实时模式暂停自动个人云镜像。手动「保存到个人云空间」发布一个独立、按版本幂等、重新核验配额的快照；后续共享修改不会覆盖这个个人副本。
- 运行复用原有运行/任务引擎、资源准入、队列、容器池和团队缓存策略。并未引入常驻执行容器，也未建立新的团队依赖安装语义。当前团队执行原有规则仍不挂载个人项目的不可变依赖代。
- 一个项目同时运行一个共享任务。当前或最近一次运行保留最多 256 KiB 的输出尾部，可在重连时重放。另保留最多 12 条归档记录，每条最多 32 KiB 输出。关闭协作模式时清空共享运行记录。
- LSP、DAP、环境检查读取各自隔离的权威源码快照；远端工具写入不会反向修改共享正文。切换模式会停止本窗口旧运行、同步与分析服务；其他窗口仍在使用的阻塞会话需要结束后再切换。
- 共享期间传统 Git 写操作、旧上传/运行入口、云终端被服务端拒绝。可通过「创建版本」保存一致的 Git 检查点；这里没有把每个按键做成 commit。
- 本轮协作以普通文本为单位。Notebook 在实时模式中作为 JSON 文本打开，不使用独立插件写入/执行；普通模式下 Notebook 插件保持原有能力。外部编辑器或未适配插件对本地文件的写入不会自动成为共享修改。
- 每项目最多 4,096 项、16 MiB 原始正文；单个基线文件上限 1 MiB，128 KiB 以上的文本和二进制保留为只读快照。节点最多每文件 200,000、每项目 500,000；持久化状态最多 64 MiB，最多 128 个会话。达到限制会拒绝新操作，保留待确认草稿；可在合适时机创建版本并重新进入模式以重建节点。

客户端草稿位于 Electron userData 的 `collaboration-drafts/`，按服务器、账号、团队、项目、分支和本地根目录隔离。epoch 变化或文件被删除后的草稿不会自动覆盖新文件；在团队下边栏可导出恢复文本。目录替换后，用户确认放弃的非草稿旧文件不作为长期备份保留。

## 验证与维护

- `client/tests/realtime-document.test.js`：Unicode、并发收敛、个人撤销、锚点。
- `client/tests/realtime-service.test.js`：故意阻塞已确认编辑的本地落盘，验证这期间输入的后续修改无需额外按键或保存即可继续发送，防止慢磁盘导致队列停滞。
- 2.9.1 / 2.6.1 修复历史工作树误阻止启用实时协作、退出登录后继续请求远端状态的问题，并缩小对方光标标签。内部映射文件不作为团队源码；真正未提交、冲突或未发布的代码仍需先处理。
- `client/tests/realtime-main.test.js`：真实文件系统、身份边界、路径限制、草稿隔离、替换失败回退。
- `client/tests/realtime-ui.spec.js`：两个真实 Electron 客户端编辑/光标/撤销、双区改名、离线合并、删除交互、共享输出。
- `client/tests/split-editors-ui.spec.js`：双文件编辑、焦点、保存/运行目标和 model 生命周期。
- `server/internal/collab/realtime_test.go`、`server/internal/handler/realtime_ws_test.go`：真实 Git、持久化重启、删除、认证 WebSocket、实际子进程运行与输入/停止、资源清理。

协议、精确限制和服务端恢复行为见 [server/REALTIME.md](../server/REALTIME.md)。这些测试进入现有 Node、TypeScript、Electron core、Go 及 race CI；不依赖生产账号。
